🏢 關於 Leeks Terminal

Q: Leeks Terminal 係咩？同 win9you 有咩關係？

A: Leeks Terminal 係一個 HK+US 即日鮮 AI 交易決策儀表板，由散戶自建、自用、自負盈虧。我哋喺 win9you.com 域名底下運作。Leeks Terminal 係產品名，win9you 係 domain。每日自動掃描 200 隻港股 + 200 隻美股，4 維度評分 + Rule-based decision 引擎。HK 200 隻 (turnover ≥ 50M HKD) + US 200 隻 (S&P 500 + Nasdaq-100 樣本)。

📊 評分 + 信號

Q: 個 score 點樣計？

A: 四維評分 (0-100)，Python-side 確定性加權 (非 LLM 自評)：

  • 估值 (PE/PB · 5%)
  • 質素 (ROE/margin · 5%)
  • 動能 (MA/RSI/deviation · 70%)
  • 資金流 (量比/大單/Relative Volume · 20%)

公式：score = 0.05 × value + 0.05 × quality + 0.70 × momentum + 0.20 × order_flow。
Day-trade 完全偏重 momentum + order flow；估值/質素只係 tiebreaker。

Q: Conservative BUY 係咩？點解只有少數信號？

A: Conservative BUY 係 Leeks Terminal 唯一 live 嘅 mean-reversion 規則，6 個 filter 條件 AND：

  1. 前日 -3% to 0% (超賣起點)
  2. m_score 30-70 (非極端)
  3. sentiment ≠ 樂觀 (避免追頂)
  4. score < 70
  5. sector ∉ Tech/Comms
  6. US only (HK 數據延遲 + yfinance 覆蓋唔齊)

所以大部分日子只有 0-3 隻 通過。14d audit bucket [70,80) 達 84% WR，paper trade n=16 達 81% WR。詳見 Conservative 規則教學 →

Q: trade_direction 點解有時「雙向」？

A: 「雙向」(both) 代表波動率足夠，long 同 short setup 都有。LLM 同時偵測到 long 入場區同 short 反彈區，user 自己揀邊個方向做。Filter (e.g. hk-buy / hk-sell / us-buy / us-sell) 可以 hide 其他方向。

Q: 點解 entry / stop / target 有時顯示「—」？

A: 個別 LLM output 唔齊全；我哋有 backfill script parse full_md 嘅 markdown bullets 拎返。如果仍然「—」表示該股真係冇明確 setup，建議觀望。詳細可去 /dashboard/{date}/reports/{code}.html 睇原始 LLM narrative。

🌏 HK vs US

Q: HK 同 US day-trade 有咩唔同？

  1. 數據延遲：HK Tencent qtimg 1-15 分鐘，US YFinance 15-20 分鐘。Day-trade 用 delayed print 做 entry 經常被 open auction 走晒。
  2. 成本：HK stamp ~0.1% 買入 + 佣金 + levy + slip，US 0 佣金但 5-10bp/side slip。即日鮮雙邊摩擦好傷。
  3. 覆蓋：HK 200 隻 (turnover ≥ 50M HKD)，US 200 隻 (S&P 500 + Nasdaq-100 樣本)。
  4. Regime：HSI 影響 HK 信號，SPX 影響 US 信號。唔好跨市場 blindly 跟單。

📝 Paper trade + 風險

Q: Paper trade 點樣先唔自欺？

  1. 至少 30-60 個 trade 樣本先睇 edge (n<30 完全 random 範圍)
  2. 區分 WR vs EV (expectancy)：WR 50% 但 avg_win < avg_loss = 長期輸錢
  3. 加 slippage + 佣金 + 港股 stamp 入 backtest
  4. Walk-forward：train 20 日 → test 5 日，唔好用同一段數據
  5. Out-of-sample 半年 live trades 先擴規模
