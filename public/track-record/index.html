📓 Track record

呢頁分兩半：上面係實測出嚟嘅基準（由 data/control_test.csv 直接讀出嚟， 唔係打字入去）；下面係你自己嘅實盤記錄（由 data/track_record.json 讀）。 兩者唔會混為一談 —— 基準係統計結論，記錄係真金白銀。

先講清楚呢個 +1 pp 係乜。
基準答嘅係「揀股有冇價值」：同一日、同一隻股、同一持倉期、同一成本， 分別用 v2 規則入場 vs 隨便入場。佢唔係話「你照抄可以賺 1%」。 實盤有三重折讓：入場係 S1 限價單（唔係每單都成交）、只有 6/176 個訊號離觸發位 喺 0.5% 之內、2–3 倉上限之下揀邊幾個本身未驗證。唯一能證偽呢個結論嘅方法 就係下面嗰個記錄，唔係再跑多個回測。

基準（實測 · 樣本外）

  • jp200：樣本外 2,187 個 v2 訊號平均 +2.354%，同日同股隨便入場嘅 93,167 個對照平均 +0.693% → 差距 +1.661 pp/單（train→test 時間切分，test t=8.87 / 6.53）。
  • us200：樣本外 2,982 個 v2 訊號平均 +1.772%，同日同股隨便入場嘅 100,636 個對照平均 +0.696% → 差距 +1.076 pp/單（train→test 時間切分，test t=7.67 / 7.03）。
同時要記住相反嗰個結論。 同一個引擎對「同一批 200 隻股票等權持有」嘅基準，組合層面 冇 alpha （美股 v2 27.18% vs 等權 27.4%，差 −0.2 pp/年）。所以正確用法係： 呢個係一個揀股工具，唔係一個要跟嘅組合。兩個基準唔同，答案就唔同。

你嘅實盤記錄

暫時 0 單記錄。

呢個係刻意留白，唔係 bug。呢一頁唯一嘅目的係記錄真實成交 —— 而家未有一單。補資料方法：打開 data/track_record.json，喺 trades 陣列每次成交加一行：

{"trades": [
{"date": "2026-10-08", "market": "us200", "ticker": "AAPL",
"entry": 332.89, "exit": 341.20, "note": "S1 限價單成交，第 10 個交易日收市離場"}
]}

market 用 us200 / jp200 / hk200；成本會自動按各市場實際費率扣除，唔使自己填 （美股 0.05%、日股 0.10%、港股 0.25% round-trip）。 下次跑 python3 scripts/build_track_record.py 就會出現喺上面。

呢頁唔會由網站落單。 訊號只係通知，落手永遠喺你嘅券商 app。記錄呢一頁亦都係人手填 —— 冇任何自動對接會幫你「記低」一單你冇做過嘅交易。
